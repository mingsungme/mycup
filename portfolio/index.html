Graphic Assets

한 장의 사진이
세 개의 자리를 채우는 법

같은 음료가 재생 화면에서는 가로로 넓게, 라이브러리에서는 카드로, 미니 플레이어에서는 작은 정사각형으로 나타납니다. 세 자리의 비율이 모두 달라서, 한 장을 어떻게 자를지 먼저 정하고 촬영 구도를 맞췄습니다.

정사각형으로 잘려도 어떤 음료인지 알아볼 수 있어야 한다 — 이 한 가지 원칙으로 18종의 구도를 통일했습니다.

재생 카드 1200×750(16:10) · 라이브러리 600×516(1:0.86) · 미니 플레이어 160×160(1:1). 18종 × 3규격 = 54장.

Craft

디자인 시안이 아니라, 동작하는 코드

호버 프리뷰가 끊기지 않도록 볼륨을 페이드하는 로직 — 이 페이지의 모든 인터랙션은 실제로 배포된 앱 코드에서 그대로 가져온 것입니다.

// 뗐다 붙였다 할 때 뚝 끊기지 않도록 볼륨 페이드 function fadeVolume(audio, from, to, duration, onDone) { clearInterval(audio._fadeTimer); const steps = 10; let i = 0; audio.volume = from; audio._fadeTimer = setInterval(() => { i++; audio.volume = Math.min(1, Math.max(0, from + (to - from) * (i / steps))); if (i >= steps) { clearInterval(audio._fadeTimer); if (onDone) onDone(); } }, duration / steps); }
